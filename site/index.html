How it works

Prepare clips for BirdNET Analyzer

Nightjar creates local files. Identification remains in BirdNET Analyzer.

  1. 01

    Inspect the recording

    Print its duration, channels, sample rate, and file size.

  2. 02

    Split it into clips

    Use fixed times or move boundaries to a quiet half-second nearby.

  3. 03

    Continue an interrupted batch

    Nightjar reuses complete clips and repairs missing or incomplete clips.

  4. 04

    Select clips for analysis

    Copy chosen clips into one folder, then choose that folder in BirdNET Analyzer.

Install from source

Install and run Nightjar

Installation requires Rust 1.85 or newer. The repository does not offer prebuilt binaries.

INSTALL AND RUN NIGHTJAR
cargo install --git https://github.com/B-Divyesh/sf-bird-audio-slicer
nightjar demo

What Nightjar does not do

Identification stays in your analyzer

Nightjar does not include a bird-identification model. It writes clips, manifests, and spectrograms for your review.
