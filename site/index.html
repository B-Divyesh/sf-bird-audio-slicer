The handoff before the model

Make the recording manageable, not mysterious.

BirdNET can identify sound. Nightjar handles the awkward scale and file preparation that comes first.

  1. 01

    Inspect the header

    See duration, channels, sample rate, and size without loading the recording into a GUI.

  2. 02

    Choose the cuts

    Use exact intervals or nudge each boundary to the quietest nearby half-second.

  3. 03

    Resume the queue

    Completed clips are verified and reused. A stopped batch continues without repeating extraction.

FIELD TERMINAL
cargo install --git https://github.com/B-Divyesh/sf-bird-audio-slicer

A useful boundary

Nightjar prepares evidence. It does not decide what sang.

No BirdNET weights, accuracy claims, public reports, accounts, or location metadata are bundled.
