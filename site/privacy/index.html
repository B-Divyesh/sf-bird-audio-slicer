Field note / Privacy

Recordings stay where they roost.

Nightjar Slicer is designed for private, local use. This policy covers the CLI and this documentation site.

The CLI

The CLI makes no network requests and includes no telemetry. It reads the recording you name and writes only to the output directory you choose. Source recordings are never modified.

Exported manifests omit the original source filename, source path, and embedded recording metadata by default. A filename can reveal a sensitive recording location. If you pass --include-source-path, that local path and filename are included because you explicitly requested them.

The browser planner

The demo reads a small WAV header slice in your browser. It does not upload audio, retain the file, use cookies, or place data in local storage. A downloaded sample manifest is created on your device.

The hosted site

No third-party scripts, fonts, analytics, advertising, or tracking pixels are present. The deployment platform may retain ordinary short-lived server access logs for security and reliability.

Your choices

Delete an output directory to remove its clips and local checkpoint. Clear the site's browser cache to remove the offline documentation copy.

Effective 27 August 2026. Questions can be raised through the project's GitHub issue tracker.
